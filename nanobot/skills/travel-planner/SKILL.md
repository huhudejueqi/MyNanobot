# 旅游攻略规划 (Travel Planner)

## 工作流程

```
用户: "帮我规划北京旅游"
  │
  ├─ 1. 用 todo 创建任务清单
  │     └─ todo(items=[搜索攻略|分析整理|输出规划])
  │
  ├─ 2. 搜索小红书攻略
  │     └─ mcp_xiaohongshu_search_feeds("目的地 旅游攻略")
  │         └─ 如果返回空或无结果，换关键词重试:
  │            "目的地 旅游" / "目的地 攻略" / "目的地 必去"
  │
  ├─ 3. 选取优质笔记查看详情
  │     └─ mcp_xiaohongshu_get_feed_detail(note_id)
  │         └─ 通常看 2-3 篇高赞笔记
  │
  ├─ 4. 更新 todo 进度
  │     └─ todo(搜索攻略 → completed, 分析整理 → in_progress)
  │
  ├─ 5. 整理成结构化攻略
  │     └─ 包含: 行程天数 / 景点 / 美食 / 交通 / 注意事项
  │
  ├─ 6. 用 todo 创建最终行程清单
  │     └─ todo(items=[Day1 景点|Day1 美食|Day2 景点|...])
  │
  └─ 7. 输出完整攻略 + 任务清单
```

## 搜索技巧

小红书搜索可能返回空（登录不稳定），要处理：

```python
# 第一次搜索
search_feeds("北京 旅游攻略")
if 无结果 or 结果太少:
    search_feeds("北京 旅游")          # 换关键词
    if 仍无结果:
        search_feeds("北京旅游攻略 景点")  # 加长关键词
```

如果多次搜索都无结果（登录失效），降级方案：
- 用 `web_search` 搜普通网页攻略
- 用 `todo` 创建手动整理的任务清单

## 攻略结构

最终输出应包含：

```
📅 推荐行程 (3-5天)
├─ Day 1: 上午景点 / 下午景点 / 美食推荐
├─ Day 2: ...
├─ ...

🏛️ 必去景点
├─ 景点1: 介绍 + 门票 + 建议游玩时间
├─ 景点2: ...

🍜 美食推荐
├─ 餐厅/小吃: 位置 + 推荐菜

🚇 交通建议

⚠️ 注意事项
├─ 最佳季节 / 穿衣建议
├─ 避坑提醒
```

## 典型 prompt 触发词

- "想去...玩"
