# 面试题记录

## 存储位置

所有面试题保存在工作区的 `interview/` 目录下：

| 文件 | 用途 |
|---|---|
| `interview/qa.md` | 主文件：所有面试题和回答，按时间倒序 |
| `interview/stats.md` | 统计：已记录题数、按主题分类、待复习标记 |

## 数据格式

`interview/qa.md` 中每个条目用以下格式：

```markdown
## Q024 — Python 装饰器如何保留原函数的元数据？

**分类:** Python / 进阶
**日期:** 2026-07-10
**掌握程度:** 待复习 | 已掌握 | 需深入
**来源:** nanobot 项目面试题 #3

### 回答

使用 `functools.wraps` 装饰器，它会将被包装函数的 `__name__`、`__doc__`、`__module__` 等属性复制到包装函数上。

### 补充

- `@functools.wraps(func)` 本质是调用 `update_wrapper(wrapper, func)`
- 即使不用 wraps，也不影响功能，只会让调试信息混乱
```

## 记录流程

当用户说"记录这题"或类似的触发词时：

1. **创建条目** — 用上述格式追加到 `interview/qa.md` 顶部
   - 编号自动递增（Q025 → Q026）
   - 分类从上下文或用户说明中提取
   - 掌握程度默认为"待复习"
2. **更新统计** — 更新 `interview/stats.md`
3. **确认** — 回复用户"已记录"并摘要条目

## 查询场景

| 用户说 | 该做什么 |
|---|---|
| "复习一下之前的面试题" | 读取 `interview/qa.md`，列出待复习条目 |
| "出一题考我" | 随机选一道"待复习"或"已掌握"的题问用户 |
| "这个分类有什么题" | 用 `grep` 按分类过滤 |
| "把 Q024 标记为已掌握" | 编辑 `interview/qa.md`，修改该条目的掌握程度 |
| "统计一下" | 读取 `interview/stats.md` |

## 复习策略

- 优先复习标记为"待复习"的条目
- 用户答对后，将掌握程度改为"已掌握"
- 用户答错或答不全，改为"需深入"，可追加补充内容
